# Лендинг «Авторская экскурсия по Санкт-Петербургу»

Учебный проект, выполненный в рамках курса **«Фронтенд-разработчик»** в Eduson Academy.

## Цель проекта

Закрепить навыки создания лендингов с использованием современных подходов к вёрстке: семантическая структура, Flexbox и Grid, стилизация форм и таблиц.

## Технологии в проекте

- **HTML5**: семантическая вёрстка, формы, таблицы, списки.
- **CSS3**: Flexbox, Grid, градиенты, тени, скругления, псевдоклассы, псевдоэлементы.
- **Git & GitHub**: управление версиями, публикация через GitHub Pages.

## Что было сделано

- Разработана структура страницы с использованием семантических тегов (`header`, `nav`, `main`, `section`, `article`, `aside`, `footer`).
- Построены сетки с помощью **Flexbox** (навигация, сайдбар, кнопка с иконкой) и **Grid** (основной макет, секции, отзывы, услуги).
- Стилизованы таблицы с «зеброй» и скруглениями.
- Реализованы формы с чекбоксами, выпадающими списками и текстовыми полями.
- Настроен `.gitignore` и проект опубликован через GitHub Pages.
