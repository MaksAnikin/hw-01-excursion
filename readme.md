# Лендинг «Авторская экскурсия по Санкт-Петербургу»

Учебный проект (домашнее задание №1), выполненный в рамках курса **«Фронтенд-разработчик»** в Edison Academy.

## 🎯 Цель проекта
Отработка навыков базовой HTML-разметки: создание структуры страницы, работа с текстом, списками, изображениями и семантическими тегами.

## 🛠 Технологии в проекте
*   **HTML5**: Использование семантических тегов (`figure`, `figcaption`, `blockquote`).
*   **Git & GitHub**: Управление версиями и публикация через GitHub Pages.
